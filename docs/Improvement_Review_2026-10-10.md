# UI·UX, 효율, 안정성 검토 — 2026-10-10

## 범위와 판단 과정

`feat/uiux-review`에서 NDEX One, Image Manager, Auto Selector, Frame, Launcher와 공통 기록 모듈을 검토했다. 서브 에이전트 3명이 Manager, Selector, Frame/Launcher를 각각 조사했고, 주 에이전트가 재현 결과와 코드를 재검토한 뒤 수정 범위를 확정했다. 이전 감사(`Improvement_Review_2026-10-09.md`)와 로드맵 7B를 기준으로 긴 작업의 조작 가능성과 사진/기록 보존을 우선했다.

수정 전 Windows / Python 3.12.10 기준선은 433개 테스트 통과였다. 확인된 결함을 수정하고 회귀 테스트를 추가했다. 버전은 0.9.3 베타 그대로이며 이번 변경은 미배포 소스 변경이다.

## 기각하거나 범위를 제한한 판단

- Frame을 닫으면 **항상** 완료 기록이 사라진다는 가설은 실제 Qt 이벤트 루프에서 재현되지 않았다. 수정 근거는 확인된 GUI 대기와 timeout 무시이며, 완료 신호가 처리되는지도 별도로 검증한다.
- Launcher 기존 스크롤/키보드 이동에서 이번 범위의 새 결함을 확인하지 못했다. 새 작업 결과를 읽는 공통 매핑만 변경한다.
- 취소는 현재 파일의 복사·검증 또는 이미지 인코딩이 끝난 뒤 적용한다. 파일 중간 강제 종료와 즉시 취소를 보장하지 않는다. One 분석은 종료 요청 후 분석 완료를 기다린다.
- Manager의 결과는 Job Results에 남지만 Manager 전용 Retry Failed는 이번 범위에 추가하지 않는다.
- 캐시 전체 용량 제한, 여유 공간 사전 점검, 외부 편집기의 XMP 해석, EXE 재빌드·설치 검증은 후속 범위다.

## 효율 확인

- 합성 탐색 트리: 원본 JPG 25개, 제외할 백업 하위 폴더 200개/파일 200개. 수정 전 `rglob` 후 필터 방식은 `scandir` 404회, 수정 후 사전 제외는 1회였으며 결과는 모두 25개로 같았다.
- 같은 실행의 단회 참고 시간은 20.18ms → 0.72ms였다. 작은 임시 파일 트리의 관측값이며 실제 SD카드/RAW 처리 속도의 보장값이 아니다.
- Frame 동일 사진 프레이밍 변경 20회에 대한 decode 작업 수는 20개 → 1개로 회귀 검증한다. 원본 내용 변경 시에는 다시 불러온다.

## 최종 검증

- 각 테스트 프로세스의 `LOCALAPPDATA`를 임시 폴더로 격리하고 Qt에는 `QT_QPA_PLATFORM=offscreen`을 사용했다.
- 실제 Tk 이벤트 루프로 worker 대기 중 timer 실행, 입력 잠금/복원, 스캔 중복 차단, 취소/종료 및 기록 실패 경고를 검증했다. Manager의 폴더 선택·진행·취소 컨트롤은 최소 1040×680에서 확인했다.
- 실제 Qt 이벤트 루프에서 종료 요청이 UI를 막지 않으며, 스레드 종료 및 완료 신호 전달 후 manifest가 저장되는지 확인했다. 취소한 원본은 `read_report → plan_retry`로 복원했다. Frame 화면은 offscreen 렌더로 점검했다.
- 교차 검토 중 Selector의 종료 대기에서 기록 실패/worker 오류가 UI와 함께 사라지는 문제를 발견해, 자동 종료를 취소하고 경고를 유지하도록 추가 수정했다. 오류 회귀 2개 포함.
- `compileall`과 `git diff --check`도 통과했다.
- 실제 카메라 RAW 대량 작업, 외부 편집기 XMP 호환성, 설치 EXE·배포 패키지는 검증하지 않았다. 이번 검증은 소스 실행·임시 자료·자동 회귀 범위다.

## 추가 UI 개편 통합 검수 — `feat/uiux-polish`

Launcher/Job Results/공통 테마(U1), One(U2), Image Manager(U3), Auto Selector(U4)가 합쳐진 `fb4abc1`과 `main` 사이의 변경을 검토했다. 아래 결과는 앞선 0.9.4 배포 검증과 별개인 소스 검수이며, EXE 재빌드나 배포는 포함하지 않는다.

기준선은 **548개 통과**였다. 추가 재현 테스트로 다음 네 문제를 확인하고 수정했다.
