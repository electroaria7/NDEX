# UI/UX 검토 — 2026-10-11

## 검토 범위와 방법

5개 앱(Launcher, NDEX One, Image Manager, Auto Selector, Frame)을 임시 LOCALAPPDATA와 샘플 촬영 폴더(한글 폴더 포함)로 실제 실행하여 기본 창 크기와 최소 창 크기의 스크린샷을 찍고, 화면 구성을 코드와 함께 평가했다.
화면이 잠긴 환경이므로 PrintWindow 기반 캡처와 Qt offscreen grab을 사용했다.
영역별 감사 후 개선을 구현했고, 구현 결과도 같은 방식으로 스크린샷을 찍어 검수했다.

## 언어 정책

- UI는 영어로 통일한다. 5개 앱 중 4개가 이미 영어였고, 한국어 UI 문구는 Auto Selector와 Frame의 경고 3개뿐이었다.
- UI 문구에서는 CR3 대신 RAW를 쓴다.
- 디스크의 폴더 이름(예: `cr3`)은 기존 백업과의 호환을 위해 유지한다.
- README와 약관은 한국어와 영어를 함께 유지한다.
- 한국어 UI가 필요해지면 앱별로 따로 두지 않고 공용 문자열 테이블(`ndex_common`)에 추가한다.

## 반영한 개선

### 0.9.5에 포함 (PR #21)

#### Launcher

- 기본·최소 크기(880×520)에서 네 단계 카드와 버튼이 스크롤 없이 보인다.
- Last 줄에는 폴더 이름을 표시하고, 전체 경로는 툴팁으로 보여 준다.
- 문제 결과는 ⚠ 표시와 빨간색으로 강조한다.
- "Open Empty"를 "Start Fresh"로 바꿨다.
- 안내 문구를 "Start with 01 Backup…"으로 바꿨다.

#### Job Results

- 버튼을 2줄로 배치해 잘리던 문제를 해결했다.
- Esc로 닫을 수 있다.
- 실패 항목을 "⚠ 파일 — 사유" 형식으로 표시한다.
- 문제가 있는 최신 작업을 자동으로 선택한다.

#### 공용 테마

- 보조 버튼에 테두리와 배경을 넣어 버튼처럼 보이게 했다.
- 툴팁 도우미를 추가했다.

#### NDEX One

- 최소 크기에서 모든 버튼과 진행 표시가 보인다.
- 중복/검증 옵션에 쉬운 이름과 한 줄 설명을 붙였다.
- 시작 전 확인 창에 파일 수, 용량, 기간, 정책, 여유 공간을 표시한다.
- 완료 창을 추가했다(백업 폴더 열기, Image Manager 열기).
- 분석 중에는 취소할 수 없다는 안내를 표시한다.
- 쓰지 않던 Preview Tree 버튼을 제거했다.
- Enter로 주 동작을 실행한다.

#### Image Manager

- 방향키가 두 칸씩 이동하던 버그를 고쳤다.
- Pick/Reject/별점 후 다음 사진으로 자동 이동한다. View 메뉴에서 끌 수 있다.
- ✓/?/✕ 상태 열을 추가했다.
- RAW/JPG 표기와 짧은 날짜를 사용한다.
- 필터 이름을 읽기 쉽게 바꾸고 별점 필터를 추가했다.
- 필터 결과가 없을 때 안내를 표시한다.
- 빈 화면에서 시작 안내를 표시한다.
- 스캔 진행 막대를 추가했다.
- 최소 크기에서도 미리보기를 유지한다.
- 보내기와 백업 전에 개수를 확인한다.
- 전체 화면에서 위치를 표시한다(예: 12 / 42).

#### Auto Selector

- 영어 UI로 통일했다.
- 화면 밖으로 잘리던 요약을 표 위의 한 줄 배너로 옮겼다.
- 후보가 여러 개인 RAW를 직접 고르는 Choose RAW 창을 추가했다.
- 선택한 행에 따라 안내 줄을 바꾸고, RAW 위치 열을 추가했다.
- Image Manager handoff 모드를 표시하고 "Use a folder instead"를 제공한다.
- 중복 정책의 이름을 쉽게 바꾸고, Replace 시 확인을 받는다.
- 복사 완료 창을 추가했다.

### feat/frame-ux 브랜치 (미릴리스)

#### Frame

- 한국어 경고를 영어로 바꾸고, 목록의 ⚠ 배지와 툴팁, 내보내기 확인 창에 표시한다.
- 가져오기 후 "8개 중 5개 열림 · RAW 2개 건너뜀" 같은 안내를 보여 준다.
- 출력 폴더 미선택/없음 상태를 표시하고, 비활성화된 Export 버튼에는 사유를 툴팁으로 보여 준다.
- 내보내기 확인 창에 크기, 형식, 색 공간, 메타데이터, 저장 위치, 파일명 예시를 표시한다.
- 충돌 시 기본값을 "Skip existing"으로 바꿨다.
- 오류 메시지를 해결 방법을 설명하는 문장으로 바꿨다.
- 결과에 맞는 완료 창 제목을 표시하고, 실패 목록과 Job Results 버튼을 제공한다.
- "Stop After This Photo"와 Esc 취소를 추가했다.
- 단축키를 추가했다: Ctrl+O, Ctrl+Shift+O, Ctrl+E, Ctrl+Shift+E, Ctrl+J, 위/아래 이동. 드래그 앤 드롭도 지원한다.
- 미리보기 캔버스에 테두리, 크기 표시, 드래그 안내를 추가했다.
- 프리셋 복제 이름에 "copy"를 붙인다.
- 출력 프로필 설명을 정리했다.
- 모두 적용하기 전에 확인을 받는다.

## 보류한 큰 재설계

아래 항목은 데이터 모델 변경이나 큰 UI 작업이 필요해 이번 작업에서 보류했다. 진행 여부를 결정해야 한다.

| 항목 | 이유 | 규모 |
| --- | --- | --- |
| Image Manager RAW+JPG를 한 줄로 묶고 Pick·별점을 쌍 전체에 적용 | 현재는 RAW에 Pick하면 JPG는 미선택이라 Backup Picked와 Send to Auto Selector 결과가 달라짐 | 중~대 |
| Image Manager 썸네일 그리드/필름스트립 | 텍스트 목록만 있어 시각적 탐색이 느림 | 대 |
| 일괄 Pick/Reject 되돌리기(Ctrl+Z) | Ctrl+A 후 X 한 번으로 전체가 Reject됨 | 중 |
| 스캔 취소와 스캔 중 목록 점진 표시 | 대량 폴더에서 1000장당 약 3분 예상(샘플 측정 0.17초/파일) | 중 |
| Frame 목록 썸네일, 통합 프리셋 관리 창, Qt Job Results 표 형식 | 각각 새 화면 구성이 필요함 | 중~대 |
| Frame 최소 창 폭(약 808px)에서 툴바가 » 메뉴로 넘어감, 프리셋 수정 표시 "*"가 작아 잘 안 보임 | 표시 크기와 배치 문제로 영향이 작음 | 소 |
| Auto Selector 경로 입력란 툴팁 | 공용 툴팁 도우미가 생겼으므로 연결만 하면 됨 | 소 |

각 묶음은 기본·최소 크기 스크린샷을 오케스트레이터가 직접 확인했다. Image Manager는 1차 검수에서 날짜 열 잘림, 별점 0 표시, 최소 크기 미리보기 소실을 발견해 보완한 뒤 병합했다.
실제 사용자 마우스 조작과 EXE 빌드 확인은 하지 않았다.
