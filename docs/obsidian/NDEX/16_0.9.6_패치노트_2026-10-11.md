# NDEX 0.9.6 Beta — 패치노트

[[00 NDEX Index|프로젝트 목차]] · [[Roadmap|로드맵]] · [[14_0.9.5_UIUX_패치노트_2026-10-10|이전 배포]] · [[15_0.9.6_검수_추가작업_2026-10-11|0.9.6 검수 기록]]

이번 업데이트는 사진을 살펴보고 고르는 과정과 프레임·출력 설정을 재사용하는 과정을 다듬었습니다. RAW 지원 범위를 넓히고, 앞으로 번역을 추가할 수 있도록 언어 설정도 마련했습니다.

## 앱별 변경

| 앱 | 달라진 점 |
| --- | --- |
| Launcher | 언어 선택과 창 크기에 맞는 카드 배치. 한국어 번역 문구는 추후 추가 |
| One | Canon CRW 백업 지원을 기본으로 켬. 옵션을 스크롤해도 주요 버튼과 진행 상태 표시 |
| Image Manager | RAW+JPG 묶음 보기, 실행 취소·다시 실행, 썸네일 격자 보기, 스캔 중 목록 표시와 취소 |
| Auto Selector | 공용 RAW 형식 목록 사용(DNG 포함). 매칭 상태와 XMP 옵션 표시 개선 |
| Frame | 목록 썸네일, 프레임·출력 프리셋 통합 관리, 내보내기 전 확인과 작업 결과 개선 |

## Image Manager — 사진 보기와 선별

- **RAW+JPG 묶음 보기:** 같은 사진의 RAW와 JPG를 한 줄로 표시하고 Pick·Maybe·Reject·별점을 두 파일에 함께 적용합니다. 기본으로 켜져 있으며 View 메뉴에서 따로 볼 수도 있습니다.
- **실행 취소·다시 실행:** 선별 상태와 별점 변경을 Ctrl+Z / Ctrl+Y 또는 Ctrl+Shift+Z로 되돌립니다. 최대 100단계까지 지원합니다.
- **썸네일 격자 보기:** G로 전환하고 Small·Medium·Large 중 크기를 고릅니다.
- **스캔 개선:** 스캔 중에도 찾은 사진을 보여 주고 Esc로 취소할 수 있습니다. 다시 스캔할 때는 바뀌지 않은 파일을 재사용합니다.
- Pick·Maybe·Reject·Clear, 내보내기와 다음 앱으로 보내기를 한 줄 툴바에 모았습니다.

## Frame — 프리셋과 내보내기

- 목록에 썸네일과 편집 여부를 표시해 작업할 사진을 찾기 쉽게 했습니다.
- **프레임·출력 프리셋을 한 창에서 관리**합니다. 새로 만들기, 복제, 편집, 이름 변경, 삭제, 기본값 지정, 현재 설정으로 사용을 지원합니다. 새 프리셋에는 현재 편집 내용이 저장됩니다.
- 내보내기 전에 크기·형식·색 공간·메타데이터·저장 위치·파일명 예시를 확인합니다. 같은 이름의 파일이 있으면 기본으로 건너뜁니다.
- 불러오기 요약, 사진별 경고, 해결 방법이 담긴 오류 안내를 정리했습니다. 완료 결과와 실패 항목은 작업 결과 표에서 확인합니다.
- 드래그 앤 드롭과 단축키로 사진을 불러오고, Esc 또는 **Stop After This Photo**로 현재 사진을 마친 뒤 내보내기를 멈출 수 있습니다.
- 긴 저장 경로가 창을 늘리지 않도록 하고, 전체 사진 설정과 선택한 사진의 조정을 구분했습니다. 전체 적용 전에는 확인 창을 표시합니다.
- 미리보기에 테두리·크기·드래그 안내를 추가하고, 내보내기 버튼이 비활성화된 이유를 툴팁으로 보여 줍니다.

## 언어 설정

- Launcher에서 **System default**, **English**, **한국어** 중 하나를 고릅니다. 선택은 다음에 앱을 시작할 때 적용됩니다.
- **한국어 번역 문구는 아직 포함되지 않았습니다.** 한국어를 골라도 화면은 영어로 표시됩니다.
- `%LOCALAPPDATA%\NDEX\locales`에 언어별 번역 파일(예: `ko.json`)을 넣으면 재설치 없이 적용할 수 있습니다. 비어 있는 문구는 영어로 표시됩니다.
- 번역 관리 절차는 [docs/Localization.md](../../Localization.md)에 있습니다.

## RAW 호환표

| 제조사 | 형식 | 확인한 샘플 | 비고 |
| --- | --- | --- | --- |
| Canon | CR3 | EOS R, EOS R6, EOS M50 | C-RAW 포함 |
| Canon | CR2 | EOS 350D, 600D, 5D Mark II(sRAW), 7D(sRAW) | |
| Canon | CRW (신규) | PowerShot G1 | One에서 기본으로 켜짐 |
| Sony | ARW | DSLR-A100, A700, NEX-5, A7, A7 IV, A1 II | 무압축·손실 압축 등 변형 포함 |
| Sony | SRF | DSC-F828 | 내장 미리보기가 작음 |
| Sony | SR2 | DSC-R1 | 내장 미리보기가 작음 |
| Nikon | NEF | D70 | |
| Nikon | NRW | Coolpix P330 | |
| Adobe | DNG | 샘플 목록에 없음 | Auto Selector에서만 매칭. One 체크박스 없음 |

샘플 19개는 raw.pixls.us의 CC0 파일입니다. 촬영일, 메타데이터, XMP 사이드카 이름, Auto Selector 매칭, 백업 복사와 SHA-256 검증을 확인했습니다.

Image Manager 미리보기는 카메라가 내장한 가장 큰 JPEG을 쓰고 RAW 방향을 적용합니다. 예: Canon CR3 1620×1080 → 최대 6000×4000, Sony A7 IV 1616×1080 → 최대 7008×4672, Nikon D70 564×372 → 3008×2000. A100, R1, F828, G1처럼 오래된 기종은 내장 미리보기가 작게 들어 있습니다. RAW 픽셀 자체를 디코딩하는 방식은 아닙니다.

추가로 실제 세로 사진 2개(Canon EOS Kiss Digital N CR2·Nikon Df NEF)가 배포본의 큰 미리보기와 격자 보기에서 올바른 방향으로 표시되는지 확인했습니다.

## 화면 개선과 오류 수정

- 작은 Windows 아이콘과 앱 제목 표시를 다듬고, Launcher 카드가 창 폭과 글자 크기에 맞춰 배치되도록 했습니다.
- One과 Auto Selector는 옵션을 스크롤해도 주요 버튼과 진행 상태가 보이도록 했습니다. One은 최소 높이 600px를 지원합니다.
- Image Manager에서 재스캔하거나 RAW 짝 파일을 추가한 뒤 실행 취소 대상이 어긋나는 문제를 고쳤습니다.
- Frame 새 프리셋이 현재 편집을 저장하도록 수정하고, 관리 창을 닫아도 **Use as current** 적용이 유지되도록 했습니다.
- Frame과 Image Manager가 창을 닫기 전에 백그라운드 작업을 정리하도록 수정했습니다.
- One의 미리보기 표를 스크롤바 옆에 다시 배치했습니다.

## 이번 배포본에서 확인한 내용

- **기존 설치본 업그레이드:** 0.9.3 → 0.9.6 설치 후 기존 설정 보존, 설치 파일 일치, 바로가기와 앱 5개 실행을 확인했습니다.
- **화면 조작:** 2880×1800 단일 화면의 200% 배율에서 배포본을 마우스로 조작해 백업·선별·RAW 추출·Frame 내보내기를 확인했습니다.
- **세로 RAW:** 위 CR2·NEF 샘플 2개의 미리보기와 썸네일 방향을 확인했습니다.
- **Evoto 7.3.5:** RAW XMP 별점과 **Read Metadata From File**을 통한 변경 사항 다시 읽기를 확인했습니다. NDEX 사용자 정의 라벨·Pick은 Evoto의 색상 라벨·선택 플래그로 변환되지 않습니다.

기존 빌드의 소스 테스트는 729개 통과, 1개 건너뜀이었습니다. 자세한 절차와 범위는 [빌드 검증](../../Release_Validation_0.9.6.md)과 [후속 검증](../../Release_Validation_0.9.6_Followup.md)에 기록했습니다.

## 알려진 제한

- 한국어 번역은 아직 없습니다. 한국어를 골라도 화면은 영어입니다.
- Lightroom 연동, Evoto 키워드와 JPEG/DNG 사이드카 처리는 아직 검증하지 않았습니다.
- 0.9.3 이외 버전에서의 업그레이드, 신규 설치·제거, 다른 세로 RAW 형식, 다른 화면 배율·다중 모니터는 아직 검증하지 않았습니다.
- 대량 RAW·SD카드 성능은 후속 과제입니다.
- EXE는 코드 서명이 없어 Windows SmartScreen 경고가 나올 수 있습니다.
