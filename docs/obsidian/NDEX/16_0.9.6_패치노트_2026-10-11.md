# NDEX 0.9.6 Beta — 패치노트

[[00 NDEX Index|프로젝트 목차]] · [[Roadmap|로드맵]] · [[14_0.9.5_UIUX_패치노트_2026-10-10|이전 배포]] · [[15_0.9.6_검수_추가작업_2026-10-11|0.9.6 검수 기록]]

언어 설정, RAW 지원 범위, Image Manager의 묶음 보기·실행 취소·썸네일 격자 보기, Frame 프리셋 관리를 정리한 공개 베타다. 통합 검수에서 찾은 문제도 함께 고쳤다.

## 앱별 변경

| 앱 | 달라진 점 |
| --- | --- |
| Launcher | 언어 선택(시스템 기본값, English, 한국어) 추가. 다음 앱 시작부터 적용 |
| One | UI 문구를 공용 번역 체계로 연결. CRW를 기본으로 켬. 미리보기 표를 스크롤바 옆에 다시 배치 |
| Image Manager | RAW+JPG를 한 장면(한 행)으로 묶어 표시. 실행 취소·다시 실행(100단계). 점진적 스캔과 취소, 빠른 재스캔. 썸네일 격자 보기(G). 한 줄 툴바 |
| Auto Selector | UI 문구를 공용 번역 체계로 연결. 공용 RAW 형식 목록 사용. DNG 매칭 |
| Frame | 목록에 썸네일 표시. 프리셋 관리(Frames·Outputs). 작업 결과 표. 툴바 최소 폭에 맞춤. 편집한 사진에 "(edited)" 표시 |

Image Manager 격자는 사진 2,000장 기준으로 격자 전환 약 9 ms, 스크롤 p95 약 5 ms로 측정했다.

## 언어 설정

- Launcher에서 **System default**, **English**, **한국어** 중 하나를 고릅니다. 선택은 다음에 앱을 시작할 때 적용됩니다.
- 한국어 번역 값은 아직 비어 있습니다. 메시지 키(일반 793개, 복수형 35개)는 `ko.json`에 모두 들어 있으므로 나중에 값만 채우면 됩니다. 그 전까지 한국어를 골라도 화면은 영어로 보입니다.
- 번역 파일은 `ndex_common/locales/<언어코드>.json`에 있습니다. 다시 빌드하지 않고 바꾸려면 `%LOCALAPPDATA%\NDEX\locales`에 언어 코드별 파일(예: `ko.json`)을 둡니다. 빈 값은 영어 원문으로 대체됩니다.
- 번역 관리 절차는 [docs/Localization.md](../../Localization.md)에 있습니다.

## RAW 호환표

| 제조사 | 형식 | 확인한 샘플 | 비고 |
| --- | --- | --- | --- |
| Canon | CR3 | EOS R, EOS R6, EOS M50 | C-RAW 포함 |
| Canon | CR2 | EOS 350D, 600D, 5D Mark II(sRAW), 7D(sRAW) | |
| Canon | CRW (신규) | PowerShot G1 | One에서 기본으로 켜짐 |
| Sony | ARW | DSLR-A100, A700, NEX-5, A7, A7 IV, A1 II | 무압축·손실 압축 등 변형 포함 |
| Sony | SRF | DSC-F828 | 내장 미리보기가 작음 |
| Sony | SR2 | DSC-R1 | 내장 미리보기가 작음 |
| Nikon | NEF | D70 | |
| Nikon | NRW | Coolpix P330 | |
| Adobe | DNG | 샘플 목록에 없음 | Auto Selector에서만 매칭. One 체크박스 없음 |

샘플 19개는 raw.pixls.us의 CC0 파일입니다. 촬영일, 메타데이터, XMP 사이드카 이름, Auto Selector 매칭, 백업 복사와 SHA-256 검증을 확인했습니다.

Image Manager 미리보기는 카메라가 내장한 가장 큰 JPEG을 쓰고 RAW 방향을 적용합니다. 예: Canon CR3 1620×1080 → 최대 6000×4000, Sony A7 IV 1616×1080 → 최대 7008×4672, Nikon D70 564×372 → 3008×2000. A100, R1, F828, G1처럼 오래된 기종은 내장 미리보기가 작게 들어 있습니다.

## 알려진 제한

- 한국어 번역은 아직 없습니다. 한국어를 골라도 화면은 영어입니다.
- Lightroom/Evoto의 XMP 해석은 검증하지 않았습니다. XMP 파일이 생성된다는 사실이 해석 성공을 뜻하지는 않습니다.
- 이전 설치본에서의 업그레이드, 고DPI 다중 모니터, 실제 세로 방향 RAW는 검증하지 않았습니다.
- RAW 픽셀은 디코딩하지 않습니다. 미리보기는 카메라가 내장한 JPEG입니다.
- 대량 RAW·SD카드 성능은 후속 과제입니다.
- EXE는 코드 서명이 없어 Windows SmartScreen 경고가 나올 수 있습니다.
