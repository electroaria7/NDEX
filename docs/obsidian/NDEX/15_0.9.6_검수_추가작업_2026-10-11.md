# 0.9.6 검수·누락 사항 및 추가 작업 로드맵

[[Roadmap|통합 로드맵]] · [[14_0.9.5_UIUX_패치노트_2026-10-10|현재 공개 배포 기록]]

## 기준과 판정

2026-10-11 검수 스냅샷이다. 최신 공개 배포는 **0.9.5 Beta**, 통합 개발 기준은 로컬/원격 `release/0.9.6 @ c8c1d34`다. GitHub Latest는 0.9.3을 가리키지만 최신 prerelease는 0.9.5다. main은 `4390ada`이고 개발 브랜치에는 main에 없는 커밋 22개가 있다.

0.9.6은 **배포 준비 미완료**다. 코드 버전도 아직 0.9.5다. 아래 미완료 작업을 이번 검수에서 수정하거나 병합한 것은 아니다. 작업 중인 Manager worktree는 수시로 바뀔 수 있으므로 통합 시 HEAD와 미커밋 상태를 다시 확인한다.

## 이전 기록 정정

- RAW 검증 전체가 미완료인 것은 아니다. `docs/RAW_Compatibility.md`에는 Canon/Sony/Nikon 19개 실제 샘플의 날짜·메타데이터·내장 JPEG·XMP 생성·매칭·SHA-256 백업 검증 기록이 있다. 이번 문서 작업에서 재실행하지 않았다.
- 남은 실제 RAW 검증은 세로 방향·대량 성능 등이다. RAW 원본 픽셀 디코딩은 현재 설계상 미지원이다. XMP 파일 생성 성공은 Lightroom/Evoto에서의 해석 확인을 뜻하지 않는다.
- 552개(0.9.5), 603개(Frame 중간 단계) 결과를 최신 개발본 완료 근거로 사용하지 않는다.
- 초기 UI/UX 문서의 shot·Undo·점진 스캔·Frame 기능 '보류'는 이후 병합으로 대체됐다. Manager 그리드는 아직 별도 작업 중이다.

## 이번 문서 정리

- PATCH_NOTES.md에 병합된 작업과 미해결 항목을 구분하여 추가했다.
- 진행 현황·로드맵·인덱스 및 실제 Obsidian vault의 현재 기준을 연결했다.
- 코드 수정·작업 병합·패키지 빌드·릴리스는 수행하지 않았다.
