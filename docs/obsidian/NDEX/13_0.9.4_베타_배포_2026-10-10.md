# 2026-10-10 — NDEX 0.9.4 Beta 배포 기록

[[00 NDEX Index|프로젝트 목차]] · [[Roadmap|로드맵]] · [[12_UIUX_효율_안정성_패치노트_2026-10-10|소스 개선 기록]]

**릴리스: `v0.9.4` GitHub prerelease.** 런타임은 `NDEX_VERSION = "0.9.4"`, `NDEX_CHANNEL = "beta"`다. 5개 EXE와 Inno Setup 설치본 재빌드 및 아래 검증을 완료했다. 배포 파일은 아래 GitHub 릴리스 링크에서 제공한다. 기존 `v0.9.3` 배포 파일은 별도로 유지한다.

## 포함한 개선

- **10월 9일 감사:** 한글 RAW 경로의 촬영일, 정확한 RAW 파일명 우선 매칭, Pick한 JPG만 Auto Selector로 전달, RAW/JPG 짝과 썸네일 갱신, XMP Pick 상태 반영, 설정 복구, Frame 색상·프로필 처리 수정.
- **Image Manager:** 백업·내보내기·XMP의 백그라운드 실행, 진행·취소, 스캔과 파일 작업의 중복 실행 방지, 취소 결과 기록, 일괄 선택 상태 저장.
- **Auto Selector:** 분석·복사·재실행 취소, 입력 잠금과 오래된 분석 무효화, 번호가 붙은 동일 RAW 재사용, 종료 중 작업·기록 오류 표시 유지.
- **One·Frame:** 작업 완료와 기록 후 종료, 취소한 미처리 파일 보존, One의 기존 대상 덮어쓰기 방지, Frame의 최신 가져오기 결과 적용과 디코딩한 미리보기 재사용.
- **공통:** 제외 폴더에 들어가기 전 탐색 차단, Launcher의 Manager 작업 결과와 XMP 작성 수 표시.

자세한 사용자 변화와 소스 회귀 근거는 [[12_UIUX_효율_안정성_패치노트_2026-10-10]] 및 저장소 `PATCH_NOTES.md`를 참조한다.

## 배포 파일

| 파일 | 용도 |
| --- | --- |
| `NDEX_v0.9.4.zip` | Launcher, 4개 작업 앱, Docs를 포함한 Windows 포터블 패키지 |
| `NDEX_Setup_0.9.4.exe` | 같은 앱 구성을 설치하는 Inno Setup 설치본 |
| `SHA256SUMS-0.9.4.txt` | 배포 파일의 SHA-256 확인용 목록 |

포터블은 압축을 푼 뒤 `NDEX_Launcher.exe`로 시작한다. `Apps` 폴더를 함께 유지한다. 설치본의 기본 설치 위치는 `C:\Program Files\NDEX`다. EXE는 코드 서명이 없는 공개 베타다.

## 검증 완료 범위

| 범위 | 결과 |
| --- | --- |
| 재빌드 | Launcher·One·Image Manager·Auto Selector·Frame의 5개 EXE 및 Inno Setup 설치본 빌드 성공 |
| 로컬 회귀 | 새 Python 3.12.10 환경에서 472개 테스트 통과 |
| CI 회귀 | Python 3.10·3.12에서 각각 472개 테스트 통과, Actions run `38035260924` |
| EXE 버전·무결성 | 5개 EXE의 내장 버전 `0.9.4 / beta`와 패키지 체크섬 확인 |
| 한글 경로 CLI smoke | One 백업 → Manager 스캔 → Selector 최초 복사 → Selector 반복 실행 → Frame export의 5개 단계 성공 |
| GUI 기본 시작 | 5개 EXE를 각각 30초 동안 숨김 실행하여 시작 오류가 없음을 확인 |

CLI smoke는 4종 작업 EXE를 사용했다. Launcher는 내장 버전과 GUI 기본 시작 검사에 포함했다. `.build_tools/smoke-0.9.4/result.json`에 각 단계의 종료 코드 0, 한글 경로 처리, 원본 해시, Selector 반복 실행의 `copied=0 / skipped=2 / failed=0` 및 기존 RAW·XMP 보존, Frame 1개 내보내기 성공을 기록했다.

소스 실행에서는 앞선 실제 Tk/Qt 이벤트 루프 테스트로 화면 응답, 취소·종료 대기, 오류 복원과 기록 보존을 검증했다. 패키지 EXE의 30초 숨김 시작 검사는 **화면 상호작용이나 정상 종료를 검증한 결과가 아니다.**

자세한 빌드 환경·파일 해시·실행 근거는 저장소의 [Release_Validation_2026-10-10.md](https://github.com/electroaria7/NDEX/blob/main/docs/Release_Validation_2026-10-10.md)를 참조한다.

## 한계와 후속 검증

- CLI smoke의 RAW는 파일명 매칭·복사 확인용 합성 자료다. 실제 카메라 RAW 디코딩과 대량 RAW·SD카드 성능은 미검증이다.
- Lightroom/Evoto의 XMP 별점·색상 라벨 해석은 미검증이다.
- 0.9.4 신규 설치·제거와 이전 버전에서의 업그레이드는 미검증이다. 설치본 생성 성공과 설치 동작 검증은 구분한다.
- 취소는 현재 파일의 복사·검증·XMP·렌더링 또는 현재 메타데이터 묶음 완료 후 적용한다. One 분석 중 닫기는 분석 완료를 기다린다.
- Manager는 취소 항목을 Job Results에 남기지만 전용 Retry Failed 기능은 제공하지 않는다.
