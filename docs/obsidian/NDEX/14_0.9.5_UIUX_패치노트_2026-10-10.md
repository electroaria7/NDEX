# NDEX 0.9.5 Beta — UI·UX 개선 패치노트

[[00 NDEX Index|프로젝트 목차]] · [[Roadmap|로드맵]] · [[13_0.9.4_베타_배포_2026-10-10|이전 배포]]

사진을 백업하고 선별한 뒤 RAW 원본을 추출하는 과정을 더 명확하게 정리한 패치다. 0.9.4의 파일 보존·취소·안전 종료 기능을 유지하며 공개 베타 상태로 배포한다.

## 앱별 변경

| 앱 | 달라진 점 |
| --- | --- |
| Launcher | 최소 크기에서 네 작업 카드를 한 줄로 표시. 짧은 폴더명과 전체 경로 툴팁, 문제 결과 강조, 새 작업 시작을 `Start Fresh`로 표시 |
| One | 중복·검증 옵션 설명, 전체 크기·여유 공간·날짜·JPG/RAW 요약, 실제 분석 목적지 확인, 다음 동작 강조와 Enter 실행, 간결한 로그·완료창 |
| Image Manager | Pick/별점/파일 종류 필터, 상태 기호, 짧은 날짜, 한 칸씩 방향키 이동, 표시 후 자동 이동 설정, 미리보기·전체 화면 위치 안내, 백업·전달 확인 |
| Auto Selector | 영어·RAW 용어 통일, 매칭 근거와 후보 폴더 표시, `Choose RAW…` 후보 선택, Pick 전달 목록의 읽기 전용 표시, 중복/XMP 옵션 안내, 완료창 |
| Job Results | 문제 작업 우선 선택, 문제 파일명·이유·폴더 표시, 버튼 두 줄 배치와 Escape 닫기, 성공·건너뜀 상세 사유 유지 |

Frame의 앱 동작은 이번 패치에서 변경하지 않았다. 공통 모듈과 0.9.5 버전을 포함하여 함께 재빌드한다.

## 빌드·배포 파일

5개 EXE와 Inno Setup 설치본을 재빌드했다. `NDEX_v0.9.5.zip`, `NDEX_Setup_0.9.5.exe`, `SHA256SUMS-0.9.5.txt`가 배포 파일이며 이전 릴리스는 별도로 유지한다. 포터블은 압축 해제 후 `NDEX_Launcher.exe`로 시작한다.

고정 의존성 환경의 552개 테스트와 Windows CI Python 3.10/3.12가 통과했다. 실제 EXE의 한글 경로 백업·스캔·RAW/XMP 보존·반복 복사·Frame 출력, 5개 앱의 30초 이상 시작 검사, 내장 모듈과 소스 대조, ZIP CRC와 파일별 SHA-256도 확인했다. 자세한 근거와 배포 해시는 아래 검증 기록에 있다.

## 통합 검수에서 수정한 네 가지

1. **필터 입력이 사진 상태를 바꾸던 문제:** 필터에 포커스를 둔 상태의 숫자·P/X·Ctrl+A가 사진의 별점·Pick·선택을 변경하지 않도록 했다. 사진 목록의 단축키와 자동 이동은 유지한다.
2. **재시도 완료 후 잘못된 폴더를 열던 문제:** One 완료창은 현재 입력란이 아니라 실제 재시도 작업의 백업 목적지를 사용한다.
3. **처리 사유 누락:** Job Results에서 사용자가 고른 RAW, 기존 RAW/XMP 보존 등의 성공·건너뜀 상세 정보를 다시 표시한다.
4. **다른 작업 결과가 열리던 문제:** Auto Selector 완료창의 Job Results는 방금 저장한 manifest를 지정한다. 이전 실패 기록이 있어도 현재 작업을 보여준다.

## 사용할 때 알아둘 점

- 표시 후 자동 이동은 Image Manager의 `View → Advance after Pick/Reject/Rating`에서 끌 수 있다. 여러 사진을 선택하면 선택한 사진에 함께 적용한다.
- RAW 후보가 여러 개이면 `Choose RAW…`에서 파일을 직접 선택한다. 선택하지 않은 모호한 항목은 복사하지 않는다.
- One의 용량 경고는 전체 입력 크기를 기준으로 하므로 중복 건너뛰기로 줄어들 용량까지 계산하지는 않는다.
- 취소는 현재 파일이나 메타데이터 묶음이 끝난 뒤 적용된다. Manager에는 전용 Retry Failed가 없다.
- 과거 1.0.1 설치본은 제거한 뒤 설치한다. EXE는 미서명 공개 베타다.
